# 문서 (docs)

숫자 야구(number-baseball)의 **실시간 온라인 대전** 기능에 대한 기획·설계·운영 기록.

- [online-multiplayer-design.md](./online-multiplayer-design.md) — 온라인 대전의 **기획과 아키텍처**.
  왜 이렇게 만들었는지, 이벤트 프로토콜·상태 머신·공정성 규칙·연출·재접속 설계·배포 구성.
- [online-troubleshooting.md](./online-troubleshooting.md) — 만들면서 실제로 부딪힌 **문제와 해결 과정**을
  시간 순서대로. 상황 → 원인 → 해결 → 교훈으로 경험적으로 정리.

> 코드 레벨 요약과 컨벤션은 저장소 루트의 [CLAUDE.md](../CLAUDE.md), 서버 배포 절차는
> [server/README.md](../server/README.md)에 있다. 이 문서들은 그보다 **한 단계 위의 맥락**(의사결정과 사연)을 남긴다.
