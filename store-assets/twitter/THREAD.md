# 트위터(X) 홍보 스레드

이미지는 전부 **1600×900 (16:9)** — X에서 안 잘리고 크게 뜨는 비율.
**트윗 1개 = 이미지 1장**으로 잇는다. 4장 묶으면 2×2로 잘린다.

올릴 때: 1번엔 링크 안 넣기(외부 링크 있으면 도달이 눌린다). 링크는 마지막 트윗에.
해시태그는 마지막에 1~2개만. 시간대는 경기 끝난 뒤 밤 9~11시.

## 영상 (`store-assets/video/`)

| 파일 | 길이 | 내용 |
| --- | --- | --- |
| `solo-play.mp4` | 24초 | 혼자 플레이 — 다섯 번 만에 216 맞히고 CLEAR까지 |
| `multi-speed.mp4` | 26초 | 3인 스피드 대전 — LG / 두산 테마 두 화면 동시, 순위판 실시간 |
| `solo-play.gif` | 6초 | 정답 맞히는 순간만 (다른 플랫폼용, 800px) |
| `raw-*.mp4` | | 배경·문구 없는 폰 화면 원본(402×874) |

전부 1600×900, h264 + 무음 AAC(X 업로드 호환).

**한 트윗에 영상과 이미지는 같이 못 올린다.** 그래서 둘 중 하나:
- **영상을 앞세우기** — 1번을 `solo-play.mp4`로 바꾸고 `01-hero.png`는 빼기. 영상이 자동재생이라 스크롤에서 눈에 더 걸린다.
- **끼워넣기** — 이미지 스레드는 그대로 두고, 3번 뒤에 `multi-speed.mp4`만 한 트윗 추가:

```
말로 하면 감이 안 오니까

셋이 같은 숫자 푸는 거 그대로 찍었어요
왼쪽 LG, 오른쪽 두산
```

## 1번 훅 대안

- `야구 없는 날에 만든 거예요`

## 단발 (스레드 안 쓸 때, 이미지 4장 — `01` `03` `04` `06`)

```
숫자야구 만들었어요

전광판 그대로 옮겨왔고
친구랑 코드 하나로 같이도 되고
설정 구석엔 구단 테마도 숨겨놨습니다

homerun-bb.vercel.app
```

- 1번 셀프 리플에 링크 하나
- 4번 리플로 팀 요청 받기
- 나중에 `몇 번 만에 맞추셨어요` 정도로 한 번 더
