# 트위터(X) 홍보 스레드

이미지는 전부 **1600×900 (16:9)**. X 타임라인에서 이 비율은 **잘리지 않고 큰 프리뷰**로 뜬다.
한 트윗에 4장을 넣으면 2×2 그리드로 **정사각형에 가깝게 잘리므로**, 아래처럼 **트윗 1개 = 이미지 1장**으로 잇는 걸 권장.
(4장 묶음으로 올리고 싶으면 `01-hero` `03-online` `04-theme` `06-cta` 조합이 잘려도 가장 덜 손해다.)

---

### 1/6 — `01-hero.png`

⚾ 야구팬이 만든 숫자 야구 웹게임, **숫자 야구**

컴퓨터가 감춘 세 자리 숫자를 스트라이크·볼·아웃으로 좁혀가는 추리 게임.
전광판 + 타자석 감성으로 통째로 만들었습니다.

설치 없이 브라우저에서 바로 👉 homerun-bb.vercel.app

---

### 2/6 — `02-rule.png`

규칙은 3초컷.

S 스트라이크 — 숫자도 자리도 맞음
B 볼 — 숫자는 있는데 자리가 다름
O 아웃 — 아예 없는 숫자

추측할 때마다 전광판에 전구가 켜집니다.
세븐세그먼트 숫자는 폰트 없이 CSS로 직접 그렸어요(오프라인에서도 안 깨지라고).

---

### 3/6 — `03-online.png`

혼자만 하면 심심하니까 온라인 대결도 넣었습니다.

⚡ 스피드 — 같은 숫자를 최대 6명이 동시에. 횟수 + 시간 합산으로 순위
🥎 주고받기 — 서로 숫자를 몰래 정하고 번갈아 한 번씩 1:1

방 코드 4자리만 공유하면 끝. 중간에 끊겨도 다시 들어가면 그대로 이어집니다.

---

### 4/6 — `04-theme.png`

그리고 숨겨둔 거 하나.

설정 구석을 톡톡 누르면 **구단 테마**가 열립니다 🐻👯
두산 베어스 / LG 트윈스 — 전광판 워터마크까지 팀 컬러로 싹 바뀜.

어디에 숨겼는지는… 직접 찾아보세요.

---

### 5/6 — `05-detail.png`

난이도는 취향대로.
3자리 / 4자리, 시도 횟수 5·10·15·직접 입력, 힌트 모드까지.

키패드에 O/B/S 메모를 찍을 수 있고,
입력칸을 **길게 누르면** 자리별 후보 숫자도 적어둘 수 있어요.

---

### 6/6 — `06-cta.png`

Vite + React + TypeScript, 서버는 Node + Socket.IO.
PWA라 홈 화면에 설치하면 오프라인에서도 돌아가고, 로그인도 없습니다.

한 판 던져보세요 👇
