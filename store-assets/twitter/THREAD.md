# 트위터(X) 홍보 스레드

이미지는 전부 **1600×900 (16:9)**. X 타임라인에서 이 비율은 잘리지 않고 큰 프리뷰로 뜬다.
한 트윗에 4장을 넣으면 2×2 그리드로 정사각형에 가깝게 잘리므로 **트윗 1개 = 이미지 1장**으로 잇는다.

**올릴 때 주의**
- 1번 트윗에는 링크를 넣지 않는다(외부 링크 있는 트윗은 도달이 눌린다). 링크는 마지막 트윗 + 1번 트윗의 셀프 리플에.
- 해시태그는 마지막에 1~2개만. 떡칠하면 광고 계정처럼 보인다.
- 올리는 시간대는 **평일 밤 9~11시** 또는 **경기 끝난 직후**(야구 타임라인이 살아있을 때).
- 스레드 다 올리고 1번 트윗 프로필 고정.

## 1번 트윗 훅 대안

훅이 스레드의 전부다. 위에 게 안 끌리면 아래로 교체.

- `숫자야구 있잖음. 그거 진짜 야구장처럼 만들어봤음`
- `야구 없는 날 뭐하냐고 물어봐서 만듦`
- `"숫자야구인데 전광판이었으면 좋겠다" 하나 때문에 여기까지 옴`
- `야구 비 와서 취소된 날에 만든 거`
- `KBO 팬 여러분 이거 하나만 봐주십쇼`

## 단발 트윗 (스레드 안 쓸 때, 이미지 4장)

`01-hero` · `03-online` · `04-theme` · `06-cta` 를 한 트윗에 (2×2로 잘리는 건 감수)

```
야구팬이 숫자야구 만들면 이렇게 됨

전광판 감성 그대로에
친구랑 코드 하나로 온라인 대결도 되고
설정 구석엔 구단 테마까지 숨겨놨음

로그인 없이 그냥 들어가서 하면 됨
homerun-bb.vercel.app
```

## 리플로 붙이면 좋은 것

- 1번 트윗 셀프 리플: `링크임 → homerun-bb.vercel.app`
- 4번 트윗 리플: 팀 요청 받는 용도. `우리 팀도요` 리플이 붙으면 그게 곧 도달임
- 나중에: 최고 기록 자랑 유도 `몇 번 만에 맞췄는지 스샷 좀`
